# Recursive Flora: Overthinking, Visualized  
A digital experience designed to help users articulate and explore the often-invisible experience of overthinking. Community-contributed metaphors are transformed into generative “data flowers” that visualize emotional complexity in a way that is both intuitive and reflective.

The site combines a data visualization gallery with a digital zine reader, integrating emotional analytics with narrative context to support multiple modes of understanding and engagement.

## Emotional Data Visualization

Each metaphor becomes a generative flower built from ML-based emotion analysis:

- **73 metaphor submissions** from overthinkers  
- **11 emotions → 11 petals**  
- **Petal length = intensity** (0–100%)  
- **Petal color = valence** (positive / neutral / negative)  
- **Consistent petal orientation** enables comparison  

This system gives structure to subjective thoughts — allowing them to be visually compared.

---

## Interaction & Navigation

Two exploration modes, for different mindsets:

- **By Category (7 themes):** Meaningful patterns + thematic focus  
- **Shuffle Mode:** Casual, curiosity-driven browsing  

Designed for smooth usage across desktop, tablet, and mobile.

---

## Interaction Flow

| User Action | System Response | Experience Goal |
|------------|----------------|----------------|
| Hover / Tap | Reveal metaphor text | Quick scanning + emotional resonance |
| Click again | Expand emotion breakdown | Reflection + deeper understanding |

Supports both quick **browsers** and deep **readers**, based on user testing insights.

## Design & Development Process

### Phase 1 — Metaphor Modeling & Emotion System
- Collected + affinity-mapped metaphors
- Applied TweetEval classifier to score emotional dimensions  
- Refined geometry, spacing, and color rules for clarity + consistency  

### Phase 2 — UX/UI Design in Figma
- Lo-fi → hi-fi prototypes with interaction testing  
- Component library + responsive motion guidelines  
- Iterated to maintain calm, reflective tone  

### Phase 3 — AI-Augmented Development
First-time web developer — learning by asking AI to code, and then asking them questions about what they're building. This was way harder than I expected, by the way! Vibe-coding is not just vibes.

- Pair-programming with ChatGPT & Claude  
- GitHub + VS Code workflow for deployment + versioning  
- Implemented FLIP animations for smoother transitions  
- Designed the system; AI accelerated execution  

This was as much a skill-building journey as a product build!
